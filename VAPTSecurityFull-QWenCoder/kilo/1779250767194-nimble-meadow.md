# Plan: Add Trial and Demo License Types

## Objective
Add two new license types to the VAPT Security plugin:
1. Trial License - 7-day validity
2. Demo Build - 15-day validity period

## Current State Analysis
- License types are defined in `includes/class-license.php` with constants: `TYPE_STANDARD` (30 days), `TYPE_PRO` (365 days), `TYPE_DEVELOPER` (never expires)
- License data stored in WordPress option `vapt_license`
- License management UI in `templates/admin-domain-control.php` shows a dropdown with the three current types
- The `VAPT_License::renew()` method calculates new expiry based on license type
- Frontend JavaScript uses `$future_expiries` array to preview expiry dates

## Implementation Steps

### 1. Update License Constants and Logic (`includes/class-license.php`)
- Add two new constants: `TYPE_TRIAL = 'trial'` and `TYPE_DEMO = 'demo'`
- Update `activate_license()` to potentially handle new types (though default remains Standard)
- Update `update_license()` validation array to include new types
- Update `renew()` method to handle expiry calculation:
  - Trial: +7 days from current expiry (or from now if expired)
  - Demo: +15 days from current expiry (or from now if expired)

### 2. Update License Management UI (`templates/admin-domain-control.php`)
- Add two new `<option>` elements in the license type `<select>`:
  ```php
  <option value="trial" <?php selected( $license_type, 'trial' ); ?>>Trial</option>
  <option value="demo" <?php selected( $license_type, 'demo' ); ?>>Demo Build</option>
  ```
- Update the `$future_expiries` array to include:
  ```php
  'trial' => date_i18n( get_option( 'date_format' ), time() + ( 7 * DAY_IN_SECONDS ) ),
  'demo'  => date_i18n( get_option( 'date_format' ), time() + ( 15 * DAY_IN_SECONDS ) - DAY_IN_SECONDS ),
  ```

### 3. Version and Changelog Updates
- Bump plugin version from 3.0.0 to **3.1.0** (MINOR version for new features)
- Update `CHANGELOG.md` with a new entry under [3.1.0] section:
  - Added Trial License (7-day validity)
  - Added Demo Build License (15-day validity)

### 4. Update Configuration Sample (`vapt-config-sample.php`)
- Add documentation for the new license types (trial and demo) in the sample configuration file to inform superadmins of their existence and validity periods

## Verification
- Test license activation with new types
- Test license renewal for trial and demo types
- Verify UI dropdown shows all 5 types
- Verify expiry preview shows correct dates in frontend
- Ensure developer type still shows "Never" expiry
